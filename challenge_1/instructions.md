# Guess the Number Game

A game where the computer picks a random number between 1 and 100, and the user keeps guessing until they get it right. After each guess, the game tells them if they're too high, too low, or correct — and at the end shows how many attempts it took.

Your requirements:

Generate a random number between 1 and 100
Ask the user to guess in a loop
After each guess, print "Too high!", "Too low!", or "You got it!"
Count the number of attempts
When they win, print something like: "Brilliant! You got it in 5 attempts."
